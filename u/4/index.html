机制与边界

第一次打开 DSH，界面会比你想象的空。这是正常的—— 它不是那种一打开就有一堆卡片要你点的软件， 它更像一个等你派活的窗口。

第一次打开，照着这四步做

最后一步说准一点：它动过的文件会出现在这一轮的结尾， 点开才在右侧打开——不是实时刷新在右边。 另外，没有 git 的目录里它只记录通过文件工具做的改动， 而且 Host 重启之后，之前几轮的这类记录会丢。别把它当审计日志用。

一个很实用的心理准备：把它当成一个能力很强、但不熟悉你情况的实习生。你交代得越具体，它做得越对。含含糊糊地派活，它也会含含糊糊地交差。

关于安装

正常的安装方式是从官网下载 Windows 安装包，双击安装，和装其它软件没有区别。装完之后，桌面上会有一个 DeepSeek Harness 图标，双击即可。

待核实
这台机器上 DSH 已经装好了，所以我写不出「从下载到安装」的逐步流程—— 官网 deepseek.com/harness 从我这里访问被反爬拦住了（HTTP 429）。 这一段需要你装一遍、或者给我一张安装界面的截图来核实； 在那之前我不会把没验证过的步骤写成教程。

命令行入口（进阶，现在可以跳过）

除了点图标，DSH 还有一个命令行入口。日常使用完全不需要它， 但等你熟了之后会有用：可以不开界面直接派任务，也能接到自动化里。 下面这几条先放在这，混个眼熟。

你自己跑一遍

现场验证

先解决一个更根本的问题：怎么把话说成它能执行的。

只存本地，不上传

预期 · 它会指出「整理」和「文件」都太模糊，然后给出带路径、带规则、带验收标准的具体说法。这些话术第 5 节会正式讲。

这次要发出去的内容
user我对着一个能读写我电脑文件的 AI 助手说「帮我整理一下文件」。请指出这句话哪里不够，并给我 3 个改写后的版本，要求具体到它不需要再反问我。

这一页的演示走的是服务商公开的 chat/completions 接口，这样你的浏览器才能直接发出去。DSH 自己内部用的是 Anthropic Messages 格式（/anthropic/v1/messages），两者字段不完全一样——这里看到的是「同一个模型、另一种调用姿势」。

请求从你的浏览器直接发往 api.deepseek.com，不经过任何中间服务器。 max_tokens = 16000。

$ dsh web
跑完你应该看到

终端会打印一个本地地址，用浏览器打开就是上面的三栏界面。

命令行入口需要先能用 dsh 命令；日常用桌面图标即可，不必配。
